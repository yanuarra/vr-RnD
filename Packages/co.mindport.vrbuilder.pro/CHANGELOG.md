# Changelog - VR Builder Pro

**v5.0.1 (2024/12/20 - Current)**
*Updated version number to match VR Builder Core*

**v5.0.0 (2024/11/11)**

*[Added]*
- Included the existing paid add-ons: Animations, Menus, Randomization, States & Data, Track & Measure.
- Outline highlighter and associate behavior, as an alternative to the material highlighter provided in the core package.
- Point at Objects behavior, displaying an arrow (or alternate prefab) that points at a specified object.
- Play Video behavior, which lets the user play 2D or 360° videos from a Resources folder.

*[Known Issues]*
- While this package still includes the demo scenes from the old paid add-ons, the demo scenes from Randomization and States & Data have been temporarily disabled as they have not been converted yet.
